# Prototype gallery results

**Status:** authored prototype evidence with a bounded strong-art-direction slice. This is not an agent-evaluation result.

## Rendered cases

The experiment route renders the same five case families with `Composition`, `CompositionNode`, the typed node/relation model, and existing HyvUI materials:

| case               | nodes | roles                                    | relation kinds   | measured overlap pairs | max ratio in `apply` | direct-positioned nodes |
| ------------------ | ----: | ---------------------------------------- | ---------------- | ---------------------: | -------------------: | ----------------------: |
| sparse             |     2 | focal-point, counterweight               | overlap          |                      1 |                0.259 |                       2 |
| dense              |     3 | field, focal-point, connector            | connect, echo    |                      0 |                    0 |                       3 |
| image-dominant     |     3 | focal-point, counterweight, frame        | anchor, frame    |                      0 |                    0 |                       3 |
| type-dominant      |     3 | focal-point, interruption, counterweight | interrupt, echo  |                      1 |                    1 |                       3 |
| atmospheric-motion |     3 | atmosphere, focal-point, connector       | overlap, connect |                      3 |                    1 |                       3 |

The measurements come from `docs/research/composition-metrics.json`, generated by
`scripts/measure-compositions.mjs` against the production preview. A ratio of `1` in the type and
atmospheric cases is intentional containment or interruption geometry, not an unbounded edge overlap.
The sparse case is the strict edge-budget test.

## Verified structural result

- records collected: 15, covering five cases × three adaptation modes;
- unique visual signatures: 6;
- overlap pairs across all modes: 15;
- all 32 Next browser contract tests pass for case rendering, policy propagation, inspection, manual-placement precedence, seeded rerendering, overlap budgets, containment, hover response, pointer motion, theme propagation, reduced-motion shutdown, mobile containment, strong art direction, visual planes, poses, semantic focal containment, and suggest-mode passivity;
- all 23 pure Next/audit tests pass through `npm run test:next`.

The resolver remains inspectable and non-magical. `suggest` records proposals without changing layout;
`apply` may perform only the declared local geometry projection; `disabled` leaves both relation
projection and pointer adaptation off. This is evidence for bounded author control, not evidence that
automatic adaptation improves art.

## What the prototype demonstrates

1. A composition can name participants by visual role rather than only by component category.
2. Relations can be inspected independently from the rendered DOM.
3. Manual placement can remain authoritative while conflicts are reported.
4. Existing HyvUI materials can be reused inside a relationship-first wrapper.
5. A static model is enough to express a sparse field, a dense readout, an image-led piece, a type-led piece, and an atmospheric depth piece without selecting a scene template.
6. A strong local art director can turn one case into a named visual thesis with poses, palette behavior, depth planes, typography as an actor, and semantic-free atmosphere.

## What it does not demonstrate yet

- that agents discover the vocabulary without additional steering;
- that a runtime art director produces better results than static CSS/authoring;
- that the five cases have sufficient visual coherence under independent agent generation;
- that all viewport sizes preserve the intended composition;
- that a public runtime should apply suggestions automatically.

Those questions require the fixed agent prompt corpus and blind paired evaluation in Phase F.

## Six-biome proof gallery

The private route `/next-lab/biomes` is a second authored experiment. It holds the content corpus constant while changing the host art ecology:

1. ceremonial reliquary;
2. ecological elegy;
3. oneiric object-poetry;
4. machine ecology;
5. manifesto print;
6. kinetic rupture.

The implementation lives in `src/lib/next-experiments/biomeGallery.ts`,
`src/lib/next-experiments/BiomeFrame.svelte`, and
`src/routes/next-lab/biomes/`. Each frame is a native `article` with a distinct direct-child
composition, a stable semantic title/body corpus, a biome-specific spatial law, time model,
viewer role, and frame mode. Focused URLs such as `/next-lab/biomes?biome=machine-ecology` make
individual frames reviewable without removing the six-item index.

The gallery is evidence that one content model can inhabit materially different structures. It is
not evidence that these six visual branches should become fixed templates, nor that the shared
editorial chrome is the final navigation system. The next comparison should test whether an agent
can choose a host biome and a limited graft from the documented art genome without collapsing the
result into one visual language.

Browser coverage is in `tests/next-biome-gallery.spec.ts`; pure catalog coverage is in
`tests/next-biome-gallery.test.ts`. The contracts cover six full-viewport frames, deep-link focus,
shared content, structural signature diversity, mobile containment, and reduced-motion behavior.
